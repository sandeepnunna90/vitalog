# Extraction Prompt v1

Human-readable documentation only. The frontmatter above is the operative definition.

This prompt is used by `TextractFallbackAdapter` (D5) when AWS Textract's minimum
field confidence falls below `THRESHOLD_FALLBACK`. The model receives the original
document image and is asked to transcribe its content into the `FallbackExtractionResult`
schema, which is then normalized into `TextractResult` shape for D6.

The prompt is intentionally narrower than the structurer prompt (D6): it transcribes
the image into a Textract-like representation (lines, key-value pairs, tables), NOT
into biomarker candidates. The structurer (D6) handles the conversion to candidates.

Vision fallback records typically carry lower composite confidence than primary-path
records, routing them to the review band rather than auto-accept.
