# Observation Prompt v1

Human-readable documentation only. The frontmatter above is the operative definition.

Used by `ObservationGenerator` (F2) to produce a 1–3 sentence plain-language description
of a single biomarker record relative to published guideline bands.

**Guardrail stack applied to this prompt:**
1. L3 banned-phrase regex (B3) runs inside `Gateway.call()` — catches clinical-advice phrases
   automatically, retries once with stricter hint, then raises `OutputValidationError`.
2. Mode B numeric verifier (B5) runs in `ObservationGenerator._attempt()` after the Gateway
   returns — ensures every number in `text` matches the retrieval set (the record + guideline
   bounds). Retries once; falls back to safe-refusal string if both attempts fail.

**Retrieval set composition (caller-built):**
- The `BiomarkerRecordRow` for the record being observed.
- One synthetic `BiomarkerRecordRow` per guideline band bound (`lower`, `upper`) from
  `TrendResult.bands`, so the verifier accepts numbers like "7.0" from "ADA target <7.0%".

**Prompt inputs:**
- `{biomarker_name}` — `original_name` from the record (e.g. "HbA1c")
- `{value}` — `canonical_value` (or `original_value` if canonical is None)
- `{unit}` — `canonical_unit` or `original_unit`
- `{collection_date}` — formatted as "Month D, YYYY" (e.g. "March 12, 2026")
- `{record_id}` — UUID string, for the model to embed in citations
- `{guideline_text}` — one line per band: "- {label}: {raw_range} (Source: {citation})"
