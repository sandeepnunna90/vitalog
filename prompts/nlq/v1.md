# NLQ Prompt v1

Human-readable documentation only. The frontmatter above is the operative definition.

Used by `NlqHandler` (F3) to answer natural-language questions about a patient's stored
biomarker records using only retrieved data — never general medical knowledge.

**Guardrail stack applied to this prompt:**
1. L3 banned-phrase regex (B3) runs inside `Gateway.call()` — catches clinical-advice phrases
   automatically, retries once, then raises `OutputValidationError`.
2. Mode B numeric verifier (B5) runs in `NlqHandler._attempt()` after the Gateway returns —
   ensures every number in `text` matches a retrieved patient record. Retries once; falls back
   to safe-refusal string if both attempts fail.

**Retrieval set composition (caller-built):**
- Accepted `BiomarkerRecordRow` records (canonical_value not None, collection_date not None,
  verified_by in auto/user/admin) fetched per recognized biomarker ID.
- NO synthetic guideline records — NLQ must only cite patient values, not target ranges.

**Prompt inputs:**
- `{query}` — the raw patient question
- `{records_text}` — one line per record: "Name: value unit on Month D, YYYY"
- `{absent_text}` — "" or "\nNote: No data found for: X, Y." for recognized-but-missing biomarkers
