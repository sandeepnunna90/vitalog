# Classification Prompt v1

Human-readable documentation only. The frontmatter above is the operative definition.

This prompt classifies an uploaded document into one of three categories that gate the
Vitalog ingestion pipeline. The conservative bias rules are intentional: it is better to
reject a lab report than to process a personal photo as biomarker data.

Subtype taxonomy is written for the full v1 scope even though capstone routing only uses
the three top-level categories. This allows v1 to grow the routing table without a prompt
version bump.
