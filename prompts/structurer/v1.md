# Structurer Prompt v1

Human-readable documentation only. The frontmatter above is the operative definition.

Used by `Structurer` (D6) to convert `TextractResult` text into `StructuredReport` JSON.
The LLM sees the serialized OCR text (KV pairs, tables, text lines) and returns one
`RawBiomarkerCandidate` per biomarker reading found.

The `llm_confidence` field is per-candidate and feeds directly into the composite confidence
computation: `min(textract_floor, llm_confidence, classification_confidence * 100)`.
Low-confidence candidates route to the review or reject band without blocking the pipeline.

Do NOT change the output schema name (`StructuredReport`) without also updating
`src/ingestion/structurer_schemas.py` and bumping the prompt version.
