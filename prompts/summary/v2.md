# Summary Prompt v1

Human-readable documentation only. The frontmatter above is the operative definition.

Used by `SummaryGenerator` (F5) to produce a one-page health summary from all stored records.

**Guardrail stack applied to this prompt:**
1. L3 banned-phrase regex (B3) runs inside `Gateway.call()` — auto-rejects clinical-advice phrases,
   retries once, then raises `OutputValidationError`.
2. Mode A numeric verifier (B4) runs in `SummaryGenerator._attempt()` after the Gateway returns —
   ensures every Citation maps to a real record in the caller-built retrieval set. Retries once;
   falls back to safe-refusal Summary (is_fallback=True) if both attempts fail.

**Retrieval set composition (caller-built):**
- All accepted `BiomarkerRecordRow` records for the patient (canonical_value not None,
  collection_date not None, verified_by in auto/user/admin).
- `retrieval_set = {r.record_id: r for r in accepted}`

**Prompt inputs:**
- `{profile_text}` — conditions (display names), medications (name + dose), allergies
- `{records_text}` — all records sorted by (original_name, collection_date);
  each line: "Name: value unit — Month D, YYYY [id=<uuid>]"
- `{data_gaps_text}` — one line per gap canonical name, or "None" if empty

**Disclaimer:**
Never generated by the LLM. Always appended verbatim by `SummaryGenerator.generate()` after
the output is constructed. The `SummaryOutput` schema has no `disclaimer` field by design.
